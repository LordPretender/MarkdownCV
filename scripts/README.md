# Scripts de MarkdownCV

- `construire_cv.py` : génère `build/` (index.html et fichiers statiques) à partir d'un fichier markdown de données et du gabarit `src/index.html` (`py -3 scripts/construire_cv.py --source <fichier.md> [--destination build]`, `--source` se passe toujours explicitement) ; génère aussi `robots.txt`, `sitemap.xml`, les balises de partage (canonical, Open Graph), le JSON-LD et le rendu PNG de l'image de partage (`og.png`) et de l'icône d'écran d'accueil (`icone.png`) par un navigateur headless (Edge ou Chrome ; sans navigateur, avertissement sans échec) ; copie l'image de partage fournie par `image` à la place de la générée ; copie le PDF fourni par `cv_pdf` sous le nom `CV_<nom>_<titre>.pdf` et ajoute le bouton de téléchargement ; valide d'abord le fichier : une erreur bloque le build (code 1, rien écrit), les avertissements s'affichent sur stderr
- `lecture_cv.py` : module partagé de lecture du markdown de données (front-matter, sections, entrées, blocs, numéros de ligne), importé par `construire_cv.py` et `valider_cv.py`, non exécutable seul
- `valider_cv.py` : liste toutes les anomalies (erreurs bloquantes, avertissements) d'un fichier markdown de données, avec numéros de ligne, dont le contrôle de `url`, de `image` si elle est renseignée (existence, dimensions d'un PNG), de `cv_pdf` si elle est renseignée (existence, extension .pdf, chemin libre absolu ou relatif au fichier source) et des longueurs du titre et de la description (`py -3 scripts/valider_cv.py --source <fichier.md>`, code de sortie 1 s'il y a au moins une erreur)
